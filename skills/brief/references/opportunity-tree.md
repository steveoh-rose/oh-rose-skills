# Opportunity solution tree

Use it when one idea is soaking up all the attention and you need to widen the field.

```
Desired outcome
  Opportunity (a user need, pain or desire)
    Solution idea
      Assumption test
    Solution idea
      Assumption test
  Opportunity
    Solution idea
      Assumption test
```

## Build one
1. **Outcome.** One measurable thing.
2. **Opportunities.** Needs, not features. "I cannot tell which option fits me" is an opportunity. "Add filters" is a solution.
3. **Solutions.** At least two per opportunity you care about: one cheap, one ambitious.
4. **Assumption tests.** The riskiest assumption per solution and the smallest test. Pick a method from `research`.
5. **Choose.** Start with the opportunity with the most value and least uncertainty. Say why.

## Rules
- Opportunities come from evidence. If it is a guess, say so.
- Never let a solution sit at the top of the tree.
- Keep it small: three opportunities, two solutions each.
