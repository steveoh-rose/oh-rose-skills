# Phrases to avoid

## Never
- crafting delightful experiences
- pixel-perfect solutions
- bridging the gap

## Also avoid
- passionate about
- user-centric solutions
- seamless, intuitive, elegant (as claims)
- leverage, synergy, ecosystem, holistic
- transformative, game-changing, world-class
- "end-to-end" without saying what the ends are
- "I wear many hats"
- "at the intersection of X and Y" unless something specific follows

## Swaps

| Instead of | Write |
| --- | --- |
| Crafted a delightful onboarding experience | Rebuilt onboarding so new customers reached their first connection in fewer steps. [add measured result] |
| Learn more | Read the case study |
| Click here | View the project |
| Submit | Send message |
| Oops, something went wrong | The message did not send. Check your connection and try again. |
| Bridging design and engineering | Designed in Figma, built in React and TypeScript |
| Pixel-perfect UI | Built to the design tokens, checked at narrow and wide widths |

Only use a swap if the facts are true. Replace invented detail with a placeholder.

## Style checks
No em dashes. No all-caps. Sentence case headings and buttons. Few exclamation marks. Short paragraphs.
